## Багшийн 10 асуулт

Хариулт богино. Файлын нэрийг хэл.

**1. Хувийн мэдээлэл хаана байдаг вэ?**

`src/data/profile.ts`. Нэр, өгүүлбэр, намтар, ур чадвар, бүтээл, имэйл, GitHub энд. Дэлгэцүүд энэ файлаас уншина. Сошиалын `url` хоосон бол товч гарахгүй. Үүнийг `contact.tsx` шалгана.

**2. Эхний дэлгэцийн story яаж солигддог вэ?**

`src/app/(tabs)/index.tsx`. Баруун `Pressable` `go(1)`, зүүн `go(-1)` дуудна. `index` төлөв солигдоно. `useEffect` дотор `requestAnimationFrame`-ээр явц 0-оос 1 болж, 1 болвол дараагийн story руу орно. Удаан дарвал `paused` болж, таймер зогсоно.

**3. Явцын зураасыг хэн зурдаг вэ?**

`src/components/StoryProgress.tsx`. Story бүрт нэг зам. Өнгөрсөн нь дүүрэн, одоогийнх нь `progress`-оор, ирээдүй нь хоосон.

**4. Бүтээлийн шургуулга яаж ажилладаг вэ?**

`src/components/WorkPager.tsx`. `usePanGesture` хурууны `translationX`-ийг авна. `react-native-reanimated`-ийн `translateX` картыг зөөнө. Хангалттай шургуулбал дараагийн индекс рүү `withTiming`-оор очно. Товч нь `show()` функцээр мөн индекс солино.

**5. Яагаад чичиргээ вэб дээр гарахгүй вэ?**

`src/lib/haptics.ts`. `Platform.OS === "web"` бол шууд буцна. Утсан дээр `expo-haptics`-ийн `impactAsync` дуудна. Товч бүрт `tapHaptic()` бий.

**6. Сэгсрэлтийг яаж мэддэг вэ?**

`src/hooks/useShake.ts`. `expo-sensors`-ийн `Accelerometer` 100 мс тутам уншина. Өмнөх хэмжилтээс зөрүү нь 1.7-оос их, 2.5 секунд өнгөрсөн бол нууц нээнэ. Эхний уншилтыг алгасна. Учир нь 0-оос таталцал руу үсрэх нь хуурамч сэгсрэлт болно. Вэб дээр `isAvailableAsync` худлаа тул сонсогч тавихгүй.

**7. Вэб дээр нууцыг яаж нээх вэ?**

`src/components/TopBar.tsx`. **Г** дээр `onLongPress` нь `open()` дуудна. Карт нь `src/components/EasterEggModal.tsx`. Текст нь `profile.easterEgg`.

**8. Хар, цагаан горим хаана хадгалагдах вэ?**

`src/theme/ThemeContext.tsx`. `mode` нь `"dark"` эсвэл `"light"`. `toggle` сольно. Өнгө нь `src/theme/colors.ts` доторх `themes`. Дэлгэц `useTheme()`-ээс `colors` авна. Апп нээхэд хар горим.

**9. Имэйл, GitHub яагаад шууд нээгддэг вэ?**

`src/lib/openLink.ts`. React Native-ийн `Linking.openURL`. Зөвхөн `mailto:` болон `https://` зөвшөөрнө. Имэйл нь `mailto:` + `profile.email`. GitHub нь `profile.github`.

**10. Өөр өргөнтэй утсанд яаж багтдаг вэ?**

`src/theme/useLayout.ts`. `useWindowDimensions` өргөн, өндрийг авна. 360-аас нарийн бол зай 16, үсэг жижгэрнэ. Агуулга 480-аас өргөн бол тэлэхгүй. `SafeAreaView` ховил, доод цэснээс зай гаргана. Эхний зургийг 390x844 гэж тогтоосон. Ингэснээр вэб дээр сервер, клиент зөрнө гэж React андуурахгүй.

Нэмэлт, асуувал: чиглүүлэгч нь Expo Router. Дэлгэц `src/app/(tabs)/` дотор. Доод цэс `src/app/(tabs)/_layout.tsx`. `Tabs`-ийг `expo-router/js-tabs`-аас авсан.
